### Experiment 5A: Half Adder and Full Adder
#### Half Adder
- Sum = A ⊕ B
- Carry = AB

#### Full Adder
- Sum = A ⊕ B ⊕ Cin
- Carry = AB + BCin + ACin

### Experiment 5B: Half Subtractor and Full Subtractor
#### Half Subtractor
- Difference = A ⊕ B
- Borrow = A'B

#### Full Subtractor
- Difference = A ⊕ B ⊕ Bin
- Borrow = A'B + A'Bin + BBin
